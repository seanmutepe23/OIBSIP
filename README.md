# OIBSIP Data Analytics Internship

This repository contains the projects completed as part of the Oasis Infobyte Data Analytics Internship.

## Projects

### Task 1 — EDA Retail Sales
Exploratory data analysis of retail sales data to identify sales trends, customer behaviour, product performance, and business insights.

### Task 2 — Customer Segmentation
Customer segmentation using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering to identify different customer groups.

### Task 3 — Data Cleaning
Data cleaning and preprocessing of an Airbnb dataset, including missing-value handling, data validation, duplicate checks, data-type correction, and preparation of a cleaned dataset.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab / Jupyter Notebook
