# Data Cleaning and Preprocessing

## Overview

This project focuses on cleaning and preparing an Airbnb dataset for analysis by identifying and addressing missing values, invalid data, duplicates, and incorrect data types.

## Objectives

- Inspect the structure and quality of the dataset.
- Identify missing values and duplicates.
- Handle missing values appropriately.
- Convert data into appropriate formats.
- Identify and remove invalid records.
- Validate the cleaned dataset.
- Save the cleaned dataset for future analysis.

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

## Project Files

- `Task 3 notebook` — Contains the complete data cleaning and preprocessing process.
- `AB_NYC_2019_cleaned.csv` — Cleaned version of the dataset.

## Data Cleaning Performed

- Missing values were identified and handled.
- Duplicate records and duplicate IDs were checked.
- Invalid price values were removed.
- Date values were converted to datetime format.
- Data types were reviewed and corrected where necessary.
- Final validation confirmed that no missing values or duplicates remained.

## Final Dataset

After cleaning, the dataset contains **48,884 rows and 16 columns**.

## Conclusion

The dataset was successfully cleaned and validated, making it suitable for further analysis and modelling.
