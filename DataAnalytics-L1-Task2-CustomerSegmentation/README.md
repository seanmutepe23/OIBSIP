# Customer Segmentation Analysis

## Overview

This project performs customer segmentation using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering.

## Objectives

- Calculate customer Recency, Frequency, and Monetary values.
- Prepare the customer-level dataset for clustering.
- Standardise the RFM variables.
- Apply K-Means clustering.
- Analyse and profile the resulting customer segments.
- Identify differences in customer purchasing behaviour.

## Tools Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook / Google Colab

## Project Files

- `Task 2 notebook` — Contains the complete customer segmentation analysis.

## Key Areas Analysed

- Recency
- Frequency
- Monetary value
- Customer clusters
- Cluster characteristics
- Customer behaviour patterns

## Conclusion

The analysis groups customers according to their purchasing behaviour, providing useful customer segments that can support targeted marketing and customer relationship strategies.
