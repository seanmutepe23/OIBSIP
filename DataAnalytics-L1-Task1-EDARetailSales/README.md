# EDA Retail Sales Analysis

## Overview

This project performs exploratory data analysis (EDA) on a retail sales dataset to identify sales patterns, customer behaviour, and business insights.

## Objectives

- Clean and prepare the retail sales data.
- Explore sales trends and patterns.
- Analyse customer purchasing behaviour.
- Identify important sales insights using Python and Pandas.
- Present findings using data visualisations.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

## Project Files

- `Task 1 notebook` — Contains the complete data analysis and visualisations.

## Key Areas Analysed

- Sales performance
- Customer behaviour
- Product-level patterns
- Trends and distributions
- Business insights from the dataset

## Conclusion

The analysis demonstrates how exploratory data analysis can be used to understand retail sales data and identify useful patterns that can support business decision-making.
